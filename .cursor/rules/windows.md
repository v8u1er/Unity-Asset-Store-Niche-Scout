# Windows 10 + PowerShell
- **OS:** Windows 10
- **Shell:** PowerShell (no bash/linux commands)
- Always use PowerShell-compatible syntax (`;` not `&&`, `Get-ChildItem` not `ls -la`, etc.)
- Paths use backslashes or forward slashes (PowerShell accepts both)
- For all Git commands, always use `git --no-pager` to prevent interactive pagers from blocking execution.
